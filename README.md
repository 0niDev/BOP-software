# Pharmaceutical ERP & Accounting System

A complete, professional ERP system for pharmaceutical manufacturing companies.

## Features

### ✅ Complete Modules

- **Authentication** - Secure login with password hashing
- **Chart of Accounts** - Full double-entry accounting
- **Party Management** - Customers and Suppliers
- **Inventory Management** - Items, stock tracking, batches
- **Sales Invoices** - Full CRUD with automatic accounting
- **Purchase Invoices** - Full CRUD with automatic accounting
- **Manufacturing** - BOM, Production Orders, stock updates
- **Expenses** - Track and categorize expenses
- **Financial Reports** - Trial Balance, P&L, Balance Sheet, Party Ledger, Cash Book
- **Export/Print** - PDF, Excel, CSV, Print

## Installation

### Prerequisites

- Python 3.9 or higher
- pip (Python package manager)
